Kids Lapis is a student-care centre management app. Children complete homework as gamified "quests", earn stars and badges, and track their own learning progress. Volunteers and parents monitor progress and offer feedback. A coordinator oversees all children and can hand sessions over to a volunteer via an AI-generated briefing.

Within the team, Jachin owned the child-facing experience end to end — everything a child sees and interacts with in the app, the gamification engine that drives their motivation, the data charts that visualise their learning, and the AI briefing extension so volunteers arrive informed. This spans the full stack: Vue 3 views and components on the frontend, Express API routes on the backend, and a shared utility library for gamification logic.

Primary ownership

  • ChildHomeView — the child's main dashboard (quests, Kueh Tin progress)
  • HomeworkQuestCard — quest lifecycle for both child and volunteer
  • LeaderboardView — weekly podium with anonymous cheer
  • SkillProgressChart / TopicSummaryChart — Chart.js data charts
  • gamification.js — points, levels, 6 badge conditions
  • All /homework/* action routes and /progress, /leaderboard endpoints

Frontend Features

  • ChildHomeView — 2-tab layout: Quests, Kueh Tin
  • Kueh Lapis hero: 4 layers, pending-points dotted fill, season badge; plate tiers (Basic → Diamond per season)
  • Badge unlock modal with confetti; toast notification stack
  • 30 s polling + visibility-change refresh
  • Overdue quest chip: original ★ struck through next to halved award (N M ★) — penalty visible before submitting
  • LeaderboardView — podium (top 3) with gold/silver/bronze crowns, ranked rows, gap-to-next notes
  • HomeworkQuestCard — submit / undo (child); verify with late penalty, reject / return (volunteer)
  • SkillProgressChart — Chart.js line; trend label (improving / steady / needs attention)
  • TopicSummaryChart — horizontal bar per subject; calm mode for parent/volunteer

Backend Features

  • PUT /homework/:id/submit — child marks quest done
  • PUT /homework/:id/unsubmit — child retracts before verify
  • PUT /homework/:id/verify — awards points; halves if late (completedAt > dueDate)
  • PUT /homework/:id/reject — returns quest, sets rejectedAt
  • GET /homework/leaderboard — weekly verified stars
  • GET /progress/:childId — per-topic accuracy + trend
  • GET /decks — question banks for homework form

Gamification Logic  (utils/gamification.js)

Homework badges
  • first-quest — 1 verified quest
  • streak-3 — 3 on-time in a row
  • quest-champion — 5 verified quests
  • bookworm — 2 English quests
  • century — 100 ★ earned
  • rising-star — 3 quests strictly before due
Levels
  • 1 level per 50 ★; resets every 200 ★ (Season)
  • Pending points shown but not banked until verified
Key design decisions
• Late penalty applied at verify time (floor(pts/2)); not at submit time
• Pending points included in badge progress display but not banked until verified
• Leaderboard uses a rolling 7-day window; reseeding required before each demo
